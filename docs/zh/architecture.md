# 架构

```
~/.claude/projects/**/*.jsonl ─┐
~/.claude.json                 │
~/.claude/cache/*.json         ├─► 读取 ──► SQLite ──► engine ──► server ──► web
~/.claude/usage-data/**        ┘  (parse)   (~/.tally)  (纯函数)   (回环)    (原生 JS)
```

没有框架，没有打包器，没有运行时依赖。唯一的生产依赖就是 Node 本身。

## `src/ingest`：读取会话记录

| 文件 | 职责 |
| --- | --- |
| `scan.ts` | 决定读什么：每个文件的字节水位，以及哪些文件变了。 |
| `parse.ts` | 把一行 JSONL 变成一个用量事件外加提取出的工具事实。**隐私在这里被强制。** |
| `toolfacts.ts` | 从一次工具调用里提取一条安全的事实：类型、shell 动词、扩展名、截短后的路径。 |
| `db.ts` | 表结构、插入语句，以及 engine 用到的读取函数。 |
| `index.ts` | 编排、增量扫描、文件监听、derived facts 版本管理。 |

改动这里之前有两个细节值得知道：

- **末尾没有换行符的那一行永远不会被消费。** Claude Code 可能正写到一半。早期版本减去了一个虚拟
  换行符，产生了 `-1` 的水位，SQLite 照单全收，然后此后每次扫描都抛错，索引就永久损坏，直到跑一次
  `--full`。现在有一个测试会把真正的半行写进真正的文件里。
- **`FACTS_VERSION`** 守着提取出来的事实。把它加一会清空 `tool_facts` 和文件水位各一次，这样改过的
  提取器不会留下一半旧的事实。缺少新列的旧表会在打开时被删掉重建，因为
  `CREATE TABLE IF NOT EXISTS` 对缺失的列保持沉默，直到第一次插入失败。

## `src/engine`：纯函数

`credits`、`cost`、`summary`、`buckets`、`activity`、`sessions`、`findings`、`behaviour`。它们通过
参数接收常量，返回朴素数据；没有一个会打开文件或套接字，所以测试起来很便宜。

有一条家规住在这里，并且已经被打破过五次：**常量由调用方传入**。一个在内部伸手去拿回退 credit 表
的函数，会悄悄把只存在于 live 表里的模型算成零，并悄悄让整整一项发现失效。

## `src/server/serve.ts`：本地服务

- 只绑定 `127.0.0.1`。
- 每个路由都是 `GET` 且只读，除了 `POST /api/insight/refresh` 和 `POST /api/explain/run`。两者都
  需要 `x-tally-token` 头，都以 `405` 拒绝 `GET`，运行期间都返回 `409`，并且都只在你在页面上同意
  之后才消耗你的额度。
- 令牌在每次服务器启动时生成并注入 HTML，不做持久化。
- `--redact` 在边界处生效，所以页面**收到的**就是哈希后的路径，而不是页面自己选择怎么显示。
- 各种缓存（事件、校准、时间区间、会话、行为）由同一处按索引状态统一失效。第二处键在别的地方的
  缓存，就是第二个需要记得清理的地方，而那个地方一定会被忘记。

## `src/insight`：两条用到模型的路径

| 路径 | 成本 | 做什么 |
| --- | --- | --- |
| `import.ts` / `readings.ts` | 免费 | 读取 Claude Code 已有的 `/insights` 输出，转成带标签的读数。 |
| `run.ts` | 昂贵 | 运行 `/insights` 本身，重新生成那份输出。 |
| `explain.ts` | 便宜 | 把页面上已有的数字发给 `claude -p`，请它解读。 |

`/insights` 不接受任何参数。这不是猜测：Claude Code 二进制里的命令定义写着 `contentLength: 0`，
而提示词构造器从不读取它的参数。所以给它挂一个语言或深度开关，等于挂一个假旋钮。`explain.ts` 正
是为此存在：几 KB 已经测出来的数字，语言和深度真正进入提示词，成本大约是重跑 `/insights` 的
三百分之一。

你同意之前看到的价格是**实测**的，不是假设的：tally 从索引里取你自己那些较短的 `sdk-cli` 会话，
报出它们的中位数。样本少于 20 个时，它报"尚未测得"，而不是给一个漂亮的数字。

## `web/`：页面

原生 ES 模块，没有构建步骤。`app.js` 负责渲染，`src/i18n/{vi,zh,en}.js` 是扁平词典，`app.css` 放
设计 token。设计遵循 console 主题：琥珀色代表人，冷蓝色代表仪器，等宽字体只留给实测值。

## 测试

- **单元测试**（`test/`，vitest）：解析、水位、credit、成本、发现、会话、行为、路径脱敏、解读。
  其中包含一个 3,000 行的"大数据"用例，好让查询计划在真实文件上受检，而不是在它自己的计划上。
- **端到端**（`e2e/`，Playwright）：真实服务对真实索引，桌面和手机两种视口。有一个测试断言页面
  从不请求 `127.0.0.1` 以外的主机。
- **CI** 在 Node 22.13、24、26 上跑单元测试，然后针对 `scripts/make-fixture.mjs` 生成的合成数据跑
  端到端。该脚本在 `~/.claude.json` 已存在时拒绝运行，因此永远不会覆盖一台真实机器。
