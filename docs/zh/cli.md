# CLI 参考

在克隆目录里运行 `node dist/cli.js <命令>`，或者链接了 bin 之后运行 `tally <命令>`。不带命令运行
会打印帮助。

---

## `tally index`

把 `~/.claude/projects/**/*.jsonl` 扫描进 `~/.tally/index.sqlite`。

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `--full` | 关 | 从第 0 字节重扫每个文件，而不是从各自的水位继续。 |

增量扫描怎么工作，以及为什么可以在 Claude Code 正在写入时运行：

- 每个文件带一个**字节水位**。下次从那里读到文件末尾。
- **末尾没有换行符的那一行不会被消费。** Claude Code 可能正写到一半；下次会把那一行完整读进来。
- 格式错误的行会被计数并跳过。一行坏数据绝不会中断几个 GB 的扫描。
- 记录以 `(request_id, uuid)` 为键用 `INSERT OR IGNORE` 插入，所以续跑的会话即使重写早先的记录，
  也不会产生重复。

输出会报告：看到／扫描／跳过的文件数，好的／坏的／降级的行数，以及新插入的记录数。"降级"指该记录
缺少 `cache_creation` 拆分，因此那一行无法区分 5 分钟与 1 小时的缓存写入。

## `tally report`

把面板上的同一批数字打印在终端里。

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `--grain=` | `day` | `hour`、`day`、`month` 或 `year`。 |
| `--tz=` | 系统时区 | 任意 IANA 时区，例如 `Asia/Shanghai` 或 `UTC`。 |

按顺序打印：你的套餐与上限、当前上报的 5 小时与 7 天百分比、校准结论、每个模型的 credit 与美元、
按所选粒度的汇总（最近 12 个区间），以及带金额的发现。

## `tally serve`

启动本地面板。

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `--port=` | `7777` | `127.0.0.1` 上的端口。 |
| `--tz=` | 系统时区 | 所有分区间数字使用的时区。 |
| `--watch` | 关 | 会话记录变化时重扫（带去抖），然后刷新数据。 |
| `--redact` | 关 | 在数据到达页面前把项目路径换成加盐哈希。 |

服务只绑定回环地址。除以下两个之外，每个路由都是 `GET` 且只读：

- `POST /api/insight/refresh` 运行 Claude Code 自己的 `/insights`。
- `POST /api/explain/run` 让本地 `claude` 可执行文件解读屏幕上已有的数字。

两者都需要 `x-tally-token` 头，令牌在服务器启动时生成并嵌入页面；两者都拒绝 `GET`；运行期间再次
调用都返回 `409`。两者都消耗你自己的额度，所以页面会先询问，并显示从你过去的无头运行里实测出来的
价格。

## `tally doctor`

检查五个数据来源，每个打印一行，并给出值得注意的警告：

- 套餐等级、模式，以及以 credit 计的 5 小时上限
- credit 常量来自哪里（`live` 来自你的 `~/.claude.json`，或内置回退表），以及覆盖了多少模型
- 当前上报的额度，以及快照有多旧
- 计费周期成本，以及你处在周期的哪个位置
- 会话文件数量与总大小
- `/insights` 的 session-meta 文件与 facet 有多少；当 facet 只覆盖部分会话时给出警告，因为那时每个
  关于卡顿的数字都必须附带样本量
- 索引上次扫描的时间；当它旧到会让校准报 `stale_index` 时给出警告

## tally 用到的路径

| 路径 | 读或写 |
| --- | --- |
| `~/.claude/projects/**/*.jsonl` | 读 |
| `~/.claude.json` | 读 |
| `~/.claude/cache/rate-limits.json` | 读 |
| `~/.claude/cache/usage-cycle.json` | 读 |
| `~/.claude/usage-data/**` | 读；只有你批准的 `/insights` 刷新才会写 |
| `~/.tally/index.sqlite` | 写：索引本身 |
| `~/.tally/explain-<lang>.json` | 写：最近一次解读，按语言分文件 |
